实施顺序：

1. 在 `tests/day2_test.cpp` 写登录、错误输入、重复发放、重启恢复、文件损坏和保存失败测试，先确认未接入功能会失败。
2. 完成校验和文件存储，再接入 `BoxManager`；文件写入成功才更新内存。
3. 接入窗口登录和发放流程；未登录不能操作，错误在窗口内提示，成功后更新表格。
4. 编译并运行完整测试，启动 Mac 应用；修正搬目录后过期的 VS Code 路径。

验收命令：`cmake -S . -B build -DCMAKE_PREFIX_PATH=/opt/homebrew -DBUILD_TESTING=ON`、`cmake --build build -j 4`、`ctest --test-dir build --output-on-failure`。
