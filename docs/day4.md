## 新增功能

1. 乘务员在“评价与意见”选择未评价乘客，进入独立乘客页。管理窗口暂时隐藏，乘客页不显示姓名、手机号或其他乘客资料。
2. 意见选填，最多 2000 字符；点击或在意见输入框外按 1 满意、2 不满意、0 不表态提交。意见框内输入数字只作为文字。
3. 保存成功后禁用评价按钮，每名乘客只能评价一次。返回按钮、Esc 和窗口关闭均要求乘务员工号与密码；失败或取消继续留在评价页。
4. 展示三类评价、未评价人数、参与率、两种满意率，以及非空意见。双击统计页中的意见行可以查看完整内容。
5. 按已评价乘客的手机号去重抽奖，选择 0 也参与；排除本航班此前已中奖号码。默认抽 1 个，可以调整为 1–999 个；候选不足时提示。
6. 保存中奖号码、操作人工号及时间，成功保存后才展示结果。重启后仍然排除本航班已中奖号码。
7. 右下角新增“新建航班”。需先回收全部盒子、完成遗留设备领取；填写新的航班信息后，先备份旧档案再建立新档案。新航班可以复用盒号。

## 统计口径

| 项目 | 计算方式 |
| --- | --- |
| 已评价人数 | 满意 + 不满意 + 不表态 |
| 未评价人数 | 登记人数 − 已评价人数 |
| 参与率 | 已评价人数 ÷ 登记人数 |
| 满意率 | 满意人数 ÷ 全部已评价人数 |
| 已表态满意率 | 满意人数 ÷（满意人数 + 不满意人数） |

分母为 0 时显示“暂无数据”。例如 4 人登记、1 人满意、1 人不满意、1 人不表态、1 人未评价，参与率为 75.0%，满意率为 33.3%，已表态满意率为 50.0%。

## 编译和演示

在项目根目录执行：

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH=/opt/homebrew -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel 4
open build/MagicBox.app
```

两个账户为 `1001`、`1002`，密码均为 `Box@123456`。

示例数据放在 `examples/day4/records.json`，包含三种评价、未评价、重复手机号和待领取设备。推荐复制到独立目录再运行，避免改动样例或正式数据：

```sh
mkdir -p .local-data/day4-demo
cp examples/day4/records.json .local-data/day4-demo/records.json
./build/MagicBox.app/Contents/MacOS/MagicBox --data-dir .local-data/day4-demo
```

每次执行复制都会重置这个演示目录；需要保留上次演示记录时，不要重复复制。完整说明见 [使用说明.md](使用说明.md)。
